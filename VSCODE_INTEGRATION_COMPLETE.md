## 🚀 **How to Use**

### **Method 1: Keyboard Shortcuts (Fastest)**
```
Ctrl+Shift+T  → Run all tests instantly
Ctrl+Shift+M  → Quick MIDI validation
```

### **Method 2: Command Palette**
1. Press `Ctrl+Shift+P`
2. Type "Tasks: Run Task"
3. Select desired test task

### **Method 3: VS Code Terminal Menu**
1. Go to `Terminal` → `Run Task...`
2. Select test task from list

### **Method 4: Status Bar**
- Click on test tasks from status bar (if configured)
